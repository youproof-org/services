Definiáljunk egy [latex]f:\Z \to \N[/latex] függvényt a következőképpen:

[latex display="true"]f(a) = \begin{cases} a &\text{ha } a\geq 0 \\ -a &\text{ha } a\lt 0 \end{cases}[/latex]

Ekkor az [latex]f(a)[/latex] természetes számot az [latex]a[/latex] egész szám abszolútértékének nevezzük. Ennek jelölése: [latex]|a|[/latex].
