Az első egyenlet baloldala az egész számok összeadásának [yp_element slug="egesz-szamok-osszeadasa" type="link" /]ja miatt így írható:

[latex display="true"][(a;b)] \oplus [(c;d)] = [(a+c;b+d)] = \dots[/latex]

Ebből a Peano-összeadás kommutativitása miatt ([yp_element slug="peano-osszeadas-kommutativitas" type="link" /]) következik, hogy az egész számok összeadása is kommutatív:

[latex display="true"]\dots = [(c+a;d+b)] = [(c;d)] \oplus [(a;b)][/latex]

Ehhez hasonlóan a második egyenletben megfogalmazott asszociativitás pedig a Peano-összeadás asszociativitására vezethető vissza:

[latex display="true"]([(a;b)] \oplus [(c;d)]) \oplus [(e;f)] = [(a+c;b+d)] \oplus [(e;f)] = \dots[/latex] [latex display="true"]\dots = [((a+c)+e;(b+d)+f)] = [(a+(c+e);b+(d+f))] = \dots[/latex] [latex display="true"]\dots = [(a;b)] \oplus [(c+e;d+f)] = [(a;b)] \oplus ([(c;d)] \oplus [(e;f)])[/latex]
