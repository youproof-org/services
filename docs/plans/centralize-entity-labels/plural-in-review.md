# Singular plural-in references: review

These 17 references use `base('plural-in')` with `suffix('in')` on a theorem whose
`labels` block has no `plural-in`, so they render the singular today. The migration
(step 4 of [plan.md](plan.md)) rewrites both calls to the same key, chosen here:

- `ine` keeps today's text: `a [N. Tétel]ben`.
- `pl-ine` makes it plural: `a [N. Tétel]ekben`.

The **ine** column is what production shows now. The bold text in the context is the
reference itself. The **Choice** column records the content owner's decision: all 17 stay `ine`, so none of them changes.

Book sections are on the chapter page under the anchor shown. A KB proof is on its own
page, and also embedded in the book section listed, under its theorem.
